Stacked PRs for GitHub

Groups stacked pull requests and shows how long each one has waited for its first human review.

Access tokens

One token per GitHub host. Using the extension on a GitHub Enterprise host (*.ghe.com) adds that host here, or add it yourself below. The quickest way to get a token is the GitHub CLI command under each host; a fine-grained token needs read access to pull requests and metadata. The token stays in this browser and is used only by the extension's background worker, never by the page.

Review SLA

The clock starts when a pull request is ready for review and stops at its first review by a person. Bots and the author do not count, and only work hours are counted.

Code search shortcut

In Chrome's address bar, type tbgs, a space and what to look for, then press Enter to search code on GitHub. Leave the repository empty to search the last repository you visited on that host.
